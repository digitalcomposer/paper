# SOFEL MR — AI Logo Placement Studio (Concept Demo)

Single-page interactive concept demo for an AI-driven tool that places brand
logos realistically into photos/video frames (mixed-reality style product
placement).

**Live demo:** https://digitalcomposer.github.io/paper/

## What this is

A self-contained HTML/CSS/JS prototype (no build step, no dependencies) used
to communicate and visualize the product concept. It is a demo, not a
production tool or a maintained library.

## Running locally

```bash
git clone https://github.com/digitalcomposer/paper.git
cd paper
open index.html   # or: python3 -m http.server
```
